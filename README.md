# 考題整理庫 — GitHub Pages 部署與更新說明

這個資料夾就是完整的網站，包含：

- `index.html`　網站主頁
- `style.css`　樣式
- `app.js`　網站邏輯（篩選、搜尋、隨機測驗等）
- `data.json`　題目資料（之後每次更新題目，改的就是這個檔案）
- `meta.json`　記錄「最後更新日期」
- `images/`　題目內附的圖片（CT、EMG、PSG 等圖片型考題用）

`exam_site_preview.html` 是給你在還沒部署上線前、先在自己電腦快速預覽用的單一檔案版本（雙擊
就能開，資料已經內嵌在檔案裡），**不需要上傳到 GitHub**，上傳時可以略過這個檔案。

## 目前題庫內容

這批資料是從你陸續附上的 32 份 Word 檔解析出來的，共 **222 題**，都屬於「神經科專科醫師甄審」這個

這批 Word 檔其實有**五種**不同排版格式：標準命題紙表格／題號＋內文兩欄表格／完全沒有欄位標籤、直接用
「(答案字母) 題幹…」開頭／連欄位標籤都被整個刪掉、只剩下按順序排列的題幹＋選項／以及最新發現的「同一

分別解析，所以不管你之後補的新檔案是哪一種排版，都可以直接丟給我處理。

**詳解狀態統計**（依 `answer` 和 `explanation` 欄位自動判定，不用手動標記）：

- ✅ 有詳解：10 題（主要來自「長庚考題」那份檔案，有 9/10 題附上完整的詳解說明）
- 🟡 只有答案：198 題（有解答字母，但目前沒有詳解文字——之後你補上詳解，我可以幫你更新，屆時會自動
  變成「✅ 有詳解」）
- 🔴 缺答案/詳解：14 題（原始 Word 檔裡這幾題「解答」欄位本身就是空白的，屬於出題老師還沒填答案的
  題目，不是解析錯誤）

有 36 題附有圖片（CT、MRI、EMG波形、PSG睡眠圖、神經切片等），瀏覽或測驗時都會顯示在題目下方。

「瀏覽題庫」和「隨機測驗」都可以依照科目、章節、題型（A／AII／C／K）、以及題目來源檔案（📄標籤）
篩選，方便你只看某一份 Word 檔的題目，或是只針對某個章節出隨機測驗。

還有一批題目是比較特殊的「組合題」（C-type / K-type）：題目會先列出幾個敘述（1、2、3、4 或 A、B），
再依照一個組合規則（例如「(A) 若1,2,3為真、(B) 若1,3為真…」）選出正確的規則選項。網站會把作答規則
和敘述分開顯示，測驗時你選的是規則選項（A~E），不是敘述本身，這樣計分才會正確。（其中「奇美_自律
神經.docx」這份檔案本身沒有標示 C/K type 的作答規則文字，是我依照題目本身的敘述數量／格式自動判斷
題型、並套用命題紙常見的標準規則文字，如果實際規則跟原始命題老師的設計不同，之後可以再跟我說調整。）

## 第一次上線：建立 Repository 並開啟 GitHub Pages

1. 登入 GitHub，右上角點「+」→「New repository」。
2. Repository name 建議取英文小寫，例如 `exam-bank`。Visibility 選 **Public**（GitHub Pages 免費方案需要 Public repo）。不用勾選 "Add a README file"。點「Create repository」。
3. 進入剛建立的空白 repo 頁面，會看到「uploading an existing file」的連結，點下去。
4. 把這個資料夾裡的檔案和 `images/` 整個資料夾（`exam_site_preview.html` 可以不用上傳）拖曳到上傳區塊。等待上傳完成後，捲到最下方按「Commit changes」。
   - 如果拖曳資料夾沒有反應，可以把整個資料夾（不含 `exam_site_preview.html`）壓縮成 zip 後，用「Add file」→「Upload files」上傳 zip，GitHub 會自動幫你解壓縮並保留資料夾結構。
5. 上方選單點「Settings」→ 左側選單點「Pages」。
6. 在「Build and deployment」→「Branch」選擇 `main`（資料夾維持 `/root`），按「Save」。
7. 等 1～2 分鐘，重新整理這個 Pages 設定頁面，畫面上方會出現一個網址，格式類似：
   `https://你的帳號.github.io/exam-bank/`
   這就是你可以分享給同學的網址。

## 之後要更新題目（補詳解、加新題、附上還沒上傳的Word檔）

1. 把新的 Word 檔（或缺的詳解文字）傳給我，我會幫你解析、合併進題庫，重新產生更新後的
   `data.json`、`meta.json`（如果有新圖片，也會一起給你 `images/` 資料夾裡新增的圖檔）。
2. 回到你在 GitHub 上的這個 repo 頁面，在 repo 首頁點「Add file」→「Upload files」，把新的
   `data.json`（和有更新的話一起上傳 `meta.json`、新的圖片檔）拖進去，GitHub 會自動偵測是取代
   同名檔案，按「Commit changes」即可。
3. 大約幾十秒到1分鐘內，網站就會自動套用最新內容，不需要重新設定 Pages。

## 資料格式（給有興趣自己動手改 data.json 的人）

```json
{
  "id": "唯一代碼",
  "subject": "科目，例如 神經科專科醫師甄審",
  "chapter": "章節／分類",
  "year": "年份（可留空字串）",
  "type": "single（單選）／multiple（複選）／combo（組合題，C-type或K-type）",
  "format": "A／A2／C／K，原始命題紙上的題型代號",
  "rule_text": "組合題才有：作答規則文字，例如 (A) A only, (B) B only, ...",
  "difficulty": "易／中等／難（可留空字串）",
  "tags": ["原始題目屬性勾選的分類，可能不只一個"],
  "question": "題幹文字",
  "images": ["images/xxx.png，可以有多張，也可以是空陣列"],
  "options": [{ "key": "A", "text": "選項內容" }],
  "answer": ["正確選項的 key，例如 A，複選/組合題可能有多個"],
  "explanation": "詳解文字，沒有就是 null",
  "source": "題目出處／文獻引用",
  "source_file": "這一題原本是從哪份Word檔解析出來的（實際檔名，方便追查來源）",
  "source_doc": "這份Word檔的好記顯示名稱，會顯示在題目卡片上的『📄』標籤（例如「長庚考題」「奇美_中風_命題紙格式」）"
}
```

`source_doc` 是從 `data/source_labels.json` 這份「檔名 → 好記名稱」對照表補上的（因為上傳時Word檔檔名
的中文字常常會遺失變成底線，單靠 `source_file` 看不出是哪份資料）。之後新增題目時，我會同步在
`source_labels.json` 裡加上新檔案的對照，再執行 `apply_source_labels.py` 幫所有題目補上這個欄位。

如果一份檔案的原始檔名本身整個是中文（上傳後會完全變成底線，連解析程式內建的「依檔名關鍵字猜章節」
都會失效），而且這份檔案裡有題目完全沒勾選任何屬性分類，我還會在 `data/chapter_overrides.json` 裡
補一筆「檔名 → 這份檔案的章節」，`apply_source_labels.py` 執行時會自動套用（只補「原本章節是空的」
題目，不會蓋掉已經從勾選框解析出來的真正章節）。

網站會自動依據 `answer` 和 `explanation` 是否有內容，判斷要顯示「✅ 有詳解」「🟡 只有答案」還是
「🔴 缺答案/詳解」，不用額外手動標記。
